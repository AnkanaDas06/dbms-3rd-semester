# DBMS Lab - 3rd Semester

This repository contains all Database Management Systems (DBMS) laboratory assignments, SQL queries, and execution outputs for the 3rd Semester.

## 📁 Repository Structure

- **`Day-01/`**: Basic SQL queries and table selections (Assignments 01–20)
- **`DAY_02/`**: Table creation, data constraints, alterations, and queries with output screenshots (Assignments 1–12)
- **`DAY_03/`**: Filtering, aggregate functions, group by, order by queries with output screenshots (Assignments 01–20)
- **`Day_04/`**: Joins, subqueries, and advanced database operations (`sql.sql`)
- **`Day_05/`**: Complex queries, nested subqueries, and set operations (`sql.sql`)
- **`Day_06/`**: Aggregate functions, date formatting, group by/having queries, and integrity constraint verification (`01.sql`–`29.sql`)
- **`Day_07/`**: Built-in SQL functions (string manipulation, numeric operations, date arithmetic, and padding) (`01.sql`–`25.sql`)
- **`Day_08/`**: Set operators (UNION, UNION ALL, INTERSECT, MINUS) and domain constraint handling (`01.sql`–`15.sql`)
- **`Day_09/`**: Multi-table queries, joins (inner, outer), subqueries, and hierarchical self-joins (`01.sql`–`16.sql`)

## 💻 Tech Stack
- **Database**: SQL / Relational DBMS (Oracle / MySQL)
- **Language**: SQL
